<h2 align="center">🧠 Project Overview</h2>

<p align="center">
  <strong>VQA using BLIP</strong> is an AI system capable of understanding images and answering natural language questions about them.  
  Leveraging the <code>Salesforce/blip-vqa-base</code> model, it combines vision and language to provide accurate answers interactively.
</p>

<p align="center">
  Users can upload multiple images, ask any number of questions per image, and view both the image and the model-generated answers in real time.
</p>

<h2 align="center" id="core-objectives">🎯 Core Objectives</h2>
<ul>
  <li>Implement pre-trained BLIP model for Visual Question Answering.</li>
  <li>Allow users to upload multiple images interactively.</li>
  <li>Answer multiple questions per image accurately.</li>
  <li>Provide a clear visualization of images alongside answers.</li>
  <li>Demonstrate real-world applicability of multimodal AI systems.</li>
</ul>

<h2 align="center" id="system-architecture">🛠️ System Architecture</h2>
<ul>
  <li>Load pre-trained BLIP processor and VQA model.</li>
  <li>Convert uploaded images to RGB and process with the BLIP processor.</li>
  <li>Generate answers using the model in a GPU/CPU-friendly manner.</li>
  <li>Display uploaded images with corresponding questions and answers.</li>
  <li>Handle multiple images and multiple questions dynamically.</li>
</ul>

<h2 align="center" id="workflow">🧪 Workflow</h2>
<ul>
  <li>Upload 2 or more images using the interactive interface.</li>
  <li>For each image, input the number of questions to ask.</li>
  <li>Input questions one by one; answers are generated using BLIP VQA model.</li>
  <li>Visualize each image with the associated question-answer pair.</li>
</ul>
